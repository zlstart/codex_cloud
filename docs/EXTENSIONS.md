# 给丰尚助手增加业务能力

模型通过 OpenAI Agents SDK 使用工具，网页负责展示执行过程和成果。扩展入口在「能力中心」，需要管理员创建；每位用户可以单独启用或关闭。

## 选择 Skills 或 MCP

| 需求 | 选择 | 示例 |
| --- | --- | --- |
| 约定工作步骤、报告格式、业务口径 | Skill | 设备选型报告、销售周报、生产能耗分析 |
| 读取企业系统或触发实际操作 | MCP | 查询 ERP、搜索知识库、创建工单 |
| 同时需要系统数据和专属方法 | 二者结合 | MCP 查询产线数据，Skill 指导计算与报告 |

Skill 是工作指引，不会凭空赋予网络连接或数据库权限。当前通用工具已经覆盖文件读取、Python/Shell 执行、图片读取、计划和文件生成。需要其他系统时，添加 MCP 工具。

## 添加一个 Skill

进入「能力中心 → 添加能力」，填写名称、描述和 Markdown 正文。描述需要说明何时使用，正文说明输入、步骤、输出与验证。示例：

```markdown
# 产线能耗分析

适用于分析用户上传的产量、电量、运行时间记录。

1. 读取真实文件，识别日期、产线、产量、用电量及其单位。
2. 检查缺失、重复、异常和停机记录；不自行把空值当作零。
3. 以 kWh/吨计算单位产量能耗，分母为零的行单独列出。
4. 对比各产线与各月份，说明样本范围和比较口径。
5. 输出可复核的 analysis.py、带中文标签的图表和 Excel 汇总。
6. 在结论中引用真实数字，区分已证实异常和待调查原因。

所有结果保存到 outputs/。生成后检查文件存在且可读取。
不要把相关性描述为因果，也不要编造设备参数。
```

运行时先给模型提供已启用 Skill 的名称和描述，模型需要时调用 `load_skill` 读取正文。更新指引应由管理员审核。当前 Skill 支持 Markdown 指令；含脚本、模板和安装步骤的完整 Skill 包需要把依赖预装进沙箱镜像，并通过用户文件或独立 MCP 提供额外资源。

## 接入企业 MCP

本版本使用 **Streamable HTTP** 传输。企业服务应部署 HTTPS 端点，例如 `https://mcp.example.com/mcp`。

1. 在服务器环境配置 `ALLOWED_MCP_HOSTS=mcp.example.com`，然后重启应用。
2. 如需鉴权，把 Bearer token 放入服务器环境变量，例如 `MCP_ERP_TOKEN`。不要粘贴到 URL、Skill 或对话。
3. 在能力中心新增 MCP，填写名称、HTTPS URL、说明和可选凭据环境变量名称。
4. 用户在自己的能力列表中启用，然后新建或继续一个会话。
5. 第一次调用工具时，网页展示工具名和参数，用户允许后执行；拒绝则将拒绝结果交回模型。

允许列表按完整主机名匹配，连接不跟随重定向。当前端点要求标准 HTTPS 端口，URL 不接受用户名、密码、查询参数或片段。凭据变量只能使用 `MCP_<NAME>_TOKEN` 命名。当前不提供 OAuth 登录、stdio 子进程或自动扩展安装流程。

MCP 服务还必须执行自己的访问控制。共享服务账号只提供服务账号的权限，不能自动代表网页当前用户。需要按员工身份访问 ERP 时，先实现企业身份映射和用户级 token，再开放相关写操作。

## 产物展示约定

- 上传文件由系统加入会话 `uploads/`，工具可以通过 `list_files` 获得实际路径。
- Python/Shell 每次调用运行在新容器中；文件保留，变量、导入与内存不保留。
- 结果写入 `outputs/`，系统发现后登记到当前会话。回复用文件名指明成果即可。
- 图片、PDF、HTML、CSV、代码和文本支持预览；Excel、Word 等支持下载。
- HTML 预览禁用脚本，外部网页图片不会在聊天中自动加载。
- 工具不能通过文件路径访问其他会话；下载地址也需要所属用户登录。

## 发布前验证一个扩展

用一份已知输入确认计算与返回值；尝试缺失字段、无权限和服务超时；确认取消任务可停止等待；确认每个远程工具在授权前没有副作用。对于写操作，MCP 服务应提供幂等参数或独立的预览/提交工具，避免调用重试造成重复业务操作。
