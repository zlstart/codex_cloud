# Skills、MCP 与子代理

“能力中心”管理组织共享的扩展。管理员可以创建、编辑、删除自定义扩展；普通成员可以查看和单独启停，自己的偏好不影响其他用户。内置 Skill 可编辑或停用，不能删除。编辑后在下一次任务加载最新配置，正在执行的任务保留启动时的配置。

## 选择能力类型

| 需求 | 能力 | 例子 |
| --- | --- | --- |
| 工作步骤、报告格式与计算口径 | Skill | 设备选型、销售周报、能耗分析 |
| 调用企业系统或受控外部操作 | MCP | 查询 ERP、知识检索、创建工单 |
| 把明确任务委派给专门助手 | 子代理 | 数据核对、报告审阅、资料研究 |

执行底座已经使用 SDK 原生 Shell / Filesystem：`exec_command`、`write_stdin`、`apply_patch`、`view_image`。Python 通过 Shell 执行，文件阅读与搜索使用容器中的常规命令。`update_plan` 记录产品任务计划。

## Skills

管理员填写名称、适用场景描述和 Markdown 正文。内容应说明输入、工作步骤、输出和验证方式，例如：

```markdown
# 产线能耗分析

适用于分析用户上传的产量、电量和运行时间记录。

1. 读取真实文件，核对日期、产线、产量、用电量及单位。
2. 检查缺失、重复、异常与停机记录，不把缺失值直接当作零。
3. 以 kWh/吨计算单位产量能耗，分母为零的记录单独列出。
4. 比较各产线与月份，说明样本范围与比较口径。
5. 将可复核脚本、图表和 Excel 汇总写入 outputs/。
6. 验证文件可读，引用实际数字，区分已证实异常与待调查原因。
```

运行器把启用的定义转为 SDK `Skill` / `Skills`，准备在 `.famsun-skills/` 下；模型先看到名称、描述与路径，再按需要读取 `SKILL.md`。该应用不再维护自己的 `list_skills` / `load_skill` 工具。模型可见的技能命名空间每次运行重新准备，管理员保存的定义仍在应用数据库中。

当前编辑器保存 Markdown 指引，不提供任意完整技能包安装。需要脚本、模板或额外依赖时，将稳定依赖预装到沙箱镜像，并通过授权用户文件或 MCP 提供任务资源。不要在技能正文中保存凭据。

## MCP

使用 SDK `MCPServerStreamableHttp`，端点如 `https://mcp.example.com/mcp`。

1. 设置服务器 `ALLOWED_MCP_HOSTS=mcp.example.com` 并重启应用。
2. 如需 Bearer 认证，在服务器设置 `MCP_ERP_TOKEN` 等变量。
3. 管理员新增或编辑 MCP 名称、说明、HTTPS 地址和可选 `token_env`；该字段只保存变量名。
4. 用户启用扩展并开始任务。每次远程工具执行前由 SDK 暂停，页面展示工具和参数，用户允许或拒绝。

允许列表准确匹配主机；端点采用标准 HTTPS 端口，不接受 URL 用户名、密码、查询参数和片段，连接不跟随重定向。凭据引用须匹配 `MCP_[A-Z0-9_]+_TOKEN`，不能引用模型密钥。`token_env: null` 可以移除已有引用；旧部署的 `FAMSUN_MCP_TOKENS` 映射仍可使用。

MCP allowlist 仅约束 MCP 连接，沙箱普通网络默认启用。工具拒绝后，助手不得通过 Shell 改发请求绕过该审批。远端 MCP 服务仍需实施自身访问控制；组织共享 token 不会自动变成当前员工的业务身份。当前没有 MCP OAuth 登录、stdio 进程或自动安装流程。

## 子代理

管理员配置名称、职责说明、指令、可选模型、最大轮数，以及该助手需要的 Skill ID / MCP ID。未指定模型时继承主模型。示例职责：

```text
你负责检查生产数据中的缺失值、重复记录和单位冲突。
读取主代理给出的文件，仅报告能够从数据验证的问题。
如需生成核对表，保存到 outputs/quality-check.csv，并返回文件名和结论。
不要直接替主代理向用户给出最终业务决策。
```

SDK `Agent.as_tool()` 将子代理作为主代理工具。子代理接收主代理编写的任务输入，使用独立上下文，不共享主聊天的 Session 历史；主代理收到结果后继续任务。子代理共用当前聊天沙箱和文件，因此可协作处理产物，但不构成彼此隔离的安全边界。

运行时取子代理选定能力与当前用户已启用能力的交集；关闭某个 Skill / MCP 后，子代理不能通过配置引用重新启用它。子代理默认没有其他委派工具，不递归调用子代理。子代理 MCP 调用仍执行同样的原生审批，其过程记录显示在相应父工具下。

## 编辑、删除与产物

通用详情接口为 `GET /api/extensions/{id}`；编辑分别使用 Skills、MCP、subagents 的类型路径，见 [API 文档](API.md)。扩展定义全局共享，启停偏好按用户保存。删除自定义 Skill / MCP 时，相应子代理引用也会清理。

每个任务只有一个聊天容器，主代理和子代理可共享当次进程 / 文件环境；下一次任务创建新容器并重用持久文件。不要假设普通 Python 命令的内存变量跨命令或跨任务存在。`uploads/` 只读，结果放在 `outputs/`，系统发现后生成授权文件记录。

预览支持 XLSX / XLS 工作表、CSV / TSV、PDF、Markdown / HTML、图片、文本 / 代码 / JSON、DOCX 文本，以及浏览器支持的音视频。Office 预览有资源与内容上限，不执行宏或公式；DOCX 不保留全部版式。预览失败或超限时下载原文件查看。

## 验证扩展

用已知输入检查计算和工具返回值，再覆盖缺失字段、无权限、超时和取消。分别测试 MCP 允许与拒绝，确认授权前没有副作用。子代理应只使用所选且已启用能力，并把结果交回主代理。写操作的远端服务应提供幂等键或明确的预览 / 提交接口，避免重试产生重复业务操作。
